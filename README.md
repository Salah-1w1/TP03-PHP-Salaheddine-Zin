## Lancer le projet

Ouvrir un terminal à la racine du projet, puis exécuter :

    & "C:\xampp\php\php.exe" -S localhost:8000

Ensuite ouvrir dans le navigateur : http://localhost:8000/exo1_bases.php

Arrêter le serveur avec Ctrl + C

## Structure du projet

| Fichier | Rôle |
|---|---|
| config.php | Constantes de l'application |
| includes/ | Entête, menu et pied de page |
| data/ | Fichiers notes.csv et notes.json créés par les scripts |
| exo1_bases.php | Partie 1 : variables, constantes, types, chaînes |
| exo2_flux.php | Partie 2 : structures de contrôle et boucles |
| exo3_tableaux.php | Partie 3 : tableaux |
| info.html / info.php | Formulaire GET |
| saisie.html / traitement.php | Formulaire POST et écriture CSV |
| liste.php | Lecture du CSV |
| export.php | Export JSON |
| login.php / profil.php / deconnexion.php | Sessions et cookies |
